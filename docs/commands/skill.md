# `agenthist skill`

Install or remove the AgentHist Skill for supported Agents.

## Usage

```text
agenthist skill install [--agent <codex|claude|opencode|pi>]... [--force]
agenthist skill uninstall
```

The command installs for every supported Agent by default. Repeat `--agent` to select specific Agents:

```bash
agenthist skill install --agent codex --agent claude
```

Running `install` again updates content generated by AgentHist. If a custom Skill already occupies the target path, the command preserves it and exits. Use `--force` when you have confirmed it should be replaced.

`uninstall` checks every supported installation path, removes Skills managed by AgentHist, and preserves custom content with the same name.

The installed Skill helps an Agent select suitable AgentHist commands and follow preview and write boundaries for imports, conversions, provider rebinding, and transactions.
