AgentHist 0.3.0 adds a desktop GUI alongside the existing CLI.

- Browse Codex, Claude Code, OpenCode and Pi in one compact directory tree, with Agent logos, search, hidden-history recovery and merged native session segments.
- Continue a conversation with another Agent; converted history appears immediately. Preview conversion impact before native writes.
- Unify Codex history providers from Settings, preview affected records, and recover or roll back transactions.
- Extract recurring experience through the selected Agent's existing API configuration. Desktop uses one model request, lossless repeated-text compaction and the configured context capacity; model checks show endpoint, protocol, latency and errors.
- Reorganized settings, theme support, terminal discovery and safer process launch on Windows, macOS and Linux.

### Downloads

- Windows x64: Setup EXE or Portable EXE.
- macOS Intel / Apple Silicon: matching x64 / arm64 DMG or application ZIP.
- Linux x64 / ARM64: DEB, RPM or AppImage.
- `AgentHist-0.3.0-source.zip`: source code from the release tag, without dependencies, build outputs or local history.
- `SHA256SUMS.txt`: checksums for every uploaded artifact.

The desktop packages include Electron; Node.js is only needed for CLI/source development. This community release is unsigned and macOS is not notarized. Verify download origin and checksums; your operating system may ask you to approve the app. Native history parsing can block a write when a record is damaged; provider configuration and credentials are not migrated.

CLI installation remains `npm install -g agenthist` (npm releases have their own publishing schedule). To use this exact CLI version immediately, build the tagged source with Node.js 24 and run `npm link`.
