# Public screenshots

Only this directory is included in Git. Original captures in `readme-pic/` are local inputs and are ignored because they may contain personal history, directories or provider addresses.

- `history.png` and `settings.png` show synthetic E2E histories and the current desktop layout. Host-specific paths are masked.
- `experience.png` and `conversion.png` are sanitized derivatives of the supplied UI captures. The endpoint and workspace were replaced with illustrative values. PNG metadata is stripped on export.
